# This is a Basic Wattage Calculator
# Python Procedural Exercise

Its main purpose is to ask the user to input the name of the electronic, its consuption and daily. The program provides the calculation based on the formula Wattage X DailyConsumption X 30 x 1000. Then, the user can choose to continue and have the program print the cost based on the total wattage consumption, or have the program terminated.

Basic instructions on how to run the program:

a) Input the name of the electronic;

b) Input the wattage consuption;

c) Input the daily usage;

d) Have the total Killowatt per month calculated and printed;

e) Choose to continue with additional cost calculation or terminate the program;

f) Input the cost per wattage per hour;

g) Have the program print the cost based on consumtpion and daily usage.

h) End the program.
