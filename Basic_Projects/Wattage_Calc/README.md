# This is a Basic Wattage Calculator
# Python Procedural Exercise

Its main purpose is to ask the user to input the name of the electronic, its consuption and daily usage for it. The program provides the calculation based on the formula Wattage X DailyConsumption X 30 x 1000. Then, the user can choose to continue and have the program print the cost based on the total wattage consuption.
